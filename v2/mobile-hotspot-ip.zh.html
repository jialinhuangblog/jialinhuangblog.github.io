為什麼接同一支 iPhone 熱點的兩台筆電連不到彼此

2026/04/07
networkhotspotiosap-isolation

兩台筆電接同一個 WiFi，用 ifconfig 查到對方的 IP，跑 nc，連得上。

兩台筆電接同一支 iPhone 的熱點，步驟一模一樣，卻什麼反應都沒有。

我原本把熱點當成一台小的 WiFi router，那為什麼同樣的步驟到了熱點上就不行呢？

連得上的情況

家裡的 WiFi，兩台筆電在同一個網路。

連得上。router 會在同一個 subnet 的裝置之間轉送封包，一般的 LAN 就是這樣運作的。

連不上的情況

iPhone 熱點，接了兩台筆電。

沒有回應，連線最後 timeout。同一個 subnet、同一行指令，就是連不上。

可能的原因：AP isolation

我看到的現象跟 AP isolation 一致。AP（也就是 iPhone）不幫連上來的 client 互相轉送封包，所以每台筆電都能連上手機，也能透過手機上網，彼此卻連不上。

在 WiFi 上，筆電 A 要給筆電 B 的 frame 會先送到手機。要是開了 isolation，手機收到就丟掉，封包停在手機這一層，沒有送到電信商，也沒經過 NAT。

Apple 沒有在文件裡寫這個行為。2017 年一位 Apple 工程師在開發者論壇上回覆，就他所知 Personal Hotspot 並不限制 client 之間的流量，不過這個功能設計的目的「只有」讓 client 上網，他不會拿這點來做產品。之後使用者的回報兩種結果都有，所以不要把互連當成一定會成功。

為什麼沒有開關

Apple 沒說過原因，我猜大概跟 Apple 重視的這幾點有關：

  1. 預設安全。在咖啡店開熱點，陌生人不應該能看見彼此開著的 nc listener。
  2. iPhone 被當成 client 在設計。Apple 把手機看成終端裝置，所以 port forwarding、DMZ、isolation 開關、QoS 這些 router 功能都沒有。
  3. 客服成本。能調的設定少，使用者來問的問題也少。

沒有使用者設定。Apple 的 NEHotspot API 是拿來連 WiFi 網路的。Apple 的 MDM schema 有開關 Personal Hotspot、禁止使用者修改它的 key，但沒有 isolation 的 key。

Android 依手機廠商而不同，Android 公開的熱點 API 也沒有 isolation 的設定。iOS 上則是沒有給使用者切換的開關。

繞過去的方法：Tailscale

最簡單的做法是用 overlay VPN，最常被推薦的是 Tailscale。

每台筆電會拿到一個 Tailscale IP（100.x.x.x），用這個 IP 互連：

Tailscale 跑在 L3，架在 internet 上面。兩台筆電都經過 iPhone 的 NAT 連到 Tailscale 的 coordination server，server 會把每台筆電的位址清單交給另一台。Tailscale 拿到清單後逐一試，看哪個位址能直接建立 WireGuard 連線。清單上有對方的 172.20.10.x，可是這條路一樣要經過手機轉送，手機開了 isolation 的話就會被攔下。清單上還有對方對外的 public IP 加 port，可是兩台筆電都經過同一個 iPhone NAT 出去，共用這個 public IP，所以筆電 A 送往這個位址的流量，要由 NAT 轉回給它後面的筆電 B。這種轉回叫做 hairpinning。

有的 NAT 支援 hairpinning，有的不支援，iPhone 的 NAT 屬於哪一種，Apple 沒有寫，這篇也沒有測。不支援的話，Tailscale 就改走自家的 DERP（Designated Encrypted Relay for Packets）relay server。不管走哪一條，筆電 A 的封包都不再直接寄給筆電 B 的 172.20.10.x，而是寄給 public IP 或 relay server。

有點諷刺的是，相隔三十公分的兩台筆電，現在可能要繞到 internet 上某台 relay server 才能連上彼此，不過連線還是通的。

不能用 Tailscale 的話，還有兩個做法：

  • 一台小的旅行用 router。iPhone 當 WAN（USB 網路共享或 WiFi client），讓旅行 router 當真正的 AP，筆電接上它之後就能互連。
  • 一台筆電用 USB 接 iPhone 上網，再開 WiFi 熱點分享給另一台筆電，這台筆電就成了 router。

兩個做法都行，只是要多帶硬體，或做一些麻煩的設定。

總結

router 轉送 LAN 流量手機不一定轉送 LAN 流量

iPhone 熱點看起來像一台小 router，但它設計來讓連上來的裝置上網，裝置之間能不能互連，Apple 沒有任何保證。
