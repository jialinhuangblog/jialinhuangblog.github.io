kubelens：把 Kubernetes cluster 畫成一張圖，也從圖上直接下指令

2026/03/03
k8skubernetesvisualization

kubectl get all -A 印出 800 行，ConfigMap、Secret、ServiceAccount 還根本不在裡面。而且這 800 行是一行一個資源，不會寫出資源之間怎麼接，看完還是不知道哪個 Service 接到哪個 Deployment，哪些 workload 共用同一個 Secret。

kubelens 把整個 cluster 畫成一張關係圖，旁邊配一個能開很多視窗的 terminal。原始碼在 GitHub。

一張圖看完整個 cluster

820 個資源、所有 namespace，畫在同一個 WebGL canvas 上。每一條線都是從 spec 讀出來的真實依賴：Service 接到它選中的 Deployment，HTTPRoute 接到 Gateway 跟後端的 Service，workload 接到它掛載的 ConfigMap、Secret 跟 PVC。點任何一個節點，側邊欄就列出它所有的連線。

不用背 flag 的 terminal

每個資源開成一個視窗，不同 kind 的視窗有不同的按鈕：Deployment 有 Rollout Status 跟 History，Pod 有 Logs 跟重啟前留下的 Previous Logs，Secret 一鍵 Decode。視窗可以並排，也能分散在好幾個 desktop 上。

cluster 關機了也能查

dev cluster 晚上會關機。kubelens 可以先把 cluster 匯出成 YAML snapshot，之後不連線也照樣畫圖，也能模擬 kubectl get 跟 describe。

什麼時候用

平常查單一資源，在 terminal 裡用 kubectl 或 k9s 比較快。kubelens 是給需要看全貌的時候用的，或是要向不會 kubectl 的人解釋 cluster 上跑了什麼。
