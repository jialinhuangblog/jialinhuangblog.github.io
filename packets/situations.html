OSPF Hello

IP protocol 89 — 兩台 router 要先有 IP 才能建鄰居

OSPF (Open Shortest Path First) 是 link-state routing protocol，每台 router 建立完整網路拓撲，跑 Dijkstra 算最短路徑。

封包直接包在 IP header 裡（Protocol 89），不用 TCP 也不用 UDP。OSPF 自己實作 reliable delivery。

用 IP multicast `224.0.0.5` (AllSPFRouters) 發 Hello，所以介面必須先設好 IP 位址才能開始建鄰居。這是它和 IS-IS 最大的差異。
