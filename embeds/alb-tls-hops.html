The article's bug. On port 80 the ALB hands Go a sealed letter, but Go only reads postcards and can't open it. The ALB gets nothing usable back, so it returns 502.

The ALB troubleshooting docs list this as a 502 cause: an SSL handshake error when connecting to a target.

ALB target group docs: the ALB doesn't validate target certificates, so self-signed or expired ones work.
